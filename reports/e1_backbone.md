## 结论

1. **ResNet50 全面最优**：test F1 0.9675，比第二名 ResNet18（0.8705）高 9.7pp，AUC 0.9946 也是全场最高 —— 方案书选 ResNet50 作保底骨干的决策被实验支持。
2. **骨干容量 + 强预训练都重要**：小容量骨干（resnet18/34）与 DenseNet121/EfficientNet-B0 的 test F1 落在 0.83-0.87 区间，与基线的差距远大于它们之间的差距；数据规模有限时，ImageNet1K_V2 权重 + 大容量骨干的红利明显。
3. **EfficientNet-B0 的 AUC(0.9766) 排名第二但 F1 最低（0.8292）**：其概率排序好、判定阈值敏感（val 阈值仅 0.0640），说明小模型概率标定不佳，按 argmax（0.5 口径）判定时漏诊偏多 —— 提示部署侧阈值策略必须与 val 联动。
4. **口径说明**：test 判定统一用 argmax(0.5 口径) 与 mj 的协议保持一致；各模型的 val 阈值已存 checkpoint，部署时按 JSON 约定读取。
