## 三、踩坑与避坑记录（给全组）

1. **环境依赖与编码坑**：在 Windows 下用 pip 安装依赖时，`requirements.txt` 如果包含中文注释会报 `UnicodeDecodeError (GBK)`。**解决方案**：将 `requirements.txt` 改为纯英文注释，并使用清华源进行安装。
2. **Git 合并踩坑**：从 main 分支拉取更新并 merge 到个人分支时，终端自动弹出了 Vim 编辑器要求输入 commit message。小白极易卡死。**解决方案**：按 `Esc` 键，输入 `:wq` 回车保存退出，或直接使用 `git merge main -m "merge main"` 命令跳过编辑器。
3. **ONNX 模型路径报错**：后端启动时出现 `ModuleNotFoundError` 或找不到模型文件。**解决方案**：必须在项目根目录下运行 `uvicorn src.backend.main:app`，且模型文件必须严格放在 `models/onnx/` 目录下。
4. **前端 3D 模型显示问题**：3D 人体模型在白色主题下完全看不清，材质油腻。**解决方案**：弃用纯透明发光材质，改为通过 Three.js 添加 `EdgesGeometry` 线框，并使用 CSS 滤镜根据主题动态调整模型亮度与色相。
5. **PDF 导出失败**：导出 PNG/PDF 时报“资源未加载”。**解决方案**：`html2canvas` 截图前必须确保所有图片加载完成（使用 `Promise.all` 等待 `img.complete`），并添加 `useCORS: true` 及 `allowTaint: true`。
