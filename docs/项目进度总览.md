## 五、⚠️ 全组必须遵守的注意事项与红线

### 5.1 实验纪律（避免成绩作废重做）

1. **test 只评一次**：所有选模/调阈值/调参都在 val 做，test 只用于最终报告；`train_baseline.py` 已内置此纪律，其他实验脚本沿用
2. **保底模型冻结**：`resnet50_baseline.pt` 禁止覆盖/重命名；后续产物另命名为 `*_se_v1.pt`、`*_cbam_v1.pt` 等
3. **单变量实验**：每次对比实验只改一个变量（骨干/注意力/增强……），seed 固定 1234，否则无法归因
4. **val 582 张只有暴涨的数字才有意义**：基线 test F1 已 0.9675，后续实验关注 val F1/AUC 曲线与混淆矩阵变化，别指望每轮大涨
5. **类别不平衡 1:2.69**：任何指标必须含 Recall/F1/AUC/混淆矩阵，**光报 Accuracy 不及格**（全猜 PNEUMONIA 就有 72.9%）
6. **增强只在 train**：val/test 只用 `eval_tf`；增强实时做，不落盘

### 5.2 环境坑（照抄命令时最容易翻车）

1. **两套环境别混用**：训练用 conda `pytorch`（完整路径运行），数据脚本用 `.venv`；`.venv` 里**没有 torch**
2. **grad-cam 包名变了**：`pip install grad-cam`（不是 `pytorch-grad-cam`），import 名不变 `pytorch_grad_cam`
3. **print 请加 `flush=True`**：重定向日志时才能看到实时进度
4. **GBK 崩 emoji**：终端报 `UnicodeEncodeError` 就先 `$env:PYTHONIOENCODING='utf-8'` 再跑（数据没问题，纯显示问题）
5. **conda 环境在 C 盘**：`C:\Users\29542\.conda\envs\`，不改也能用，只是占 C 盘；组内其他人装新环境时留意

### 5.3 协作红线

1. **数据只在 `data/raw/`（只读）和 `data/processed/`（生成物）**，不许改官方 val 或重新发明划分（一切以 `split_manifest.csv` 为准）
2. **不用官方 16 张 val**；不引入未公开/含隐私数据（合规见 `docs/数据合规说明.md`）
3. **不做超范围任务**：先二分类保底，多分类/其他任务保底版稳定后才议
4. **每人完成的节点必须写日志**（`logs/你的缩写.md`），并同步更新本总览的「二、里程碑总表」和「四、每人的下一步」
