## 五、⚠️ 全组必须遵守的注意事项与红线

### 5.1 实验与算法纪律
1. **test 只评一次**：所有选模/调阈值都在 val 做，test 仅用于最终报告。
2. **保底模型冻结**：`resnet50_baseline.pt` 禁止覆盖/重命名；在线推理统一走 ONNX FP32。
3. **类别不平衡 1:2.69**：任何指标必须含 Recall/F1/AUC/混淆矩阵，光报 Accuracy 不及格。

### 5.2 全栈联调与启动避坑（杨思彤补充）
1. **模型与路径**：后端启动必须在**项目根目录**下执行 `uvicorn src.backend.main:app --reload`，且 `.onnx` 模型需放入 `models/onnx/`。
2. **多模态融合约定**：前端表单（年龄/体温等）通过 JSON 提交，后端使用晚期融合规则（Late Fusion）计算 `final_prob`，前端展示联合概率。
3. **依赖安装**：后端安装包请务必使用国内镜像（如清华源），且 `requirements.txt` 中不得包含中文注释。
4. **PDF 导出坑**：`html2canvas` 截图时需确保图片加载完毕且配置 `useCORS: true`，否则会生成空白。

### 5.3 协作红线
1. **数据只在 `data/raw/`（只读）和 `data/processed/`（生成物）**，不许改官方 val 或重新发明划分。
2. **不做超范围任务**：坚决守住“二分类”底线，不在此版本扩展多分类或 DICOM 解析。
3. **每人完成的节点必须写日志**（`logs/你的缩写.md`），并同步更新本总览的「二、里程碑总表」和「四、每人的下一步」。
