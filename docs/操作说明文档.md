# 肺炎 X 光片智能辅助诊断系统 · 操作说明手册

## 1. 系统简介
本系统是一个面向医生的肺炎 X 光片智能辅助筛查参考工具。系统基于 ResNet50（ONNX 格式）深度学习模型，支持单张或多张胸部 X 光片的上传分析，结合患者临床特征进行多模态晚期融合推理，输出分类概率，并通过 Grad-CAM 热力图展示模型的关注区域。

> ⚠️ **重要声明**：本系统仅作为辅助筛查工具，输出结果（NORMAL / PNEUMONIA）不构成临床诊断、治疗建议或医疗决策依据，最终诊断请以执业医师综合判断为准。

## 3. 核心功能操作流程

### 3.1 登录系统
1. 在浏览器中打开系统，自动跳转至登录页。
2. 输入演示账号和密码，点击“进入辅助筛查系统”。
3. （首次登录）系统会自动弹出新手引导，指导您了解左侧菜单和核心功能。

### 3.2 辅助筛查工作台（核心功能）
1. 点击左侧导航栏的 **“辅助筛查”**。
2. **上传影像**：将 X 光片（支持 JPG / JPEG / PNG，单张 ≤ 10MB）拖入上传区域，或点击选择文件。每次最多支持 3 张影像。
3. **填写临床信息（可选）**：系统支持“影像 + 临床”多模态融合。您可以输入患者的年龄、体温、咳嗽天数。若留空，系统将仅基于影像模型输出结果。
4. **开始分析**：点击右下角的 **“开始 AI 多模态分析”** 按钮。此时影像上会出现全息扫描线动画。
5. **查看结果**：
   - **联合预测风险**：展示结合影像和临床信息后的最终风险概率。
   - **影像视图**：左右对比展示原始影像与 Grad-CAM 热力图。您可以使用下方的滑块调节热力图透明度，或开启窗宽窗位调节（Windowing）模拟阅片环境。
   - **阈值动态调节**：拖动下方的阈值滑块，您可以看到“NORMAL / PNEUMONIA”的判定结果和颜色徽章实时变化。
6. **保存与导出**：点击“保存至历史记录”将结果入库。点击“导出诊断报告”可一键生成包含影像、结果与免责声明的 PDF 文件。

### 3.3 历史记录管理
1. 点击左侧导航栏的 **“历史记录”**。
2. 列表展示了过往的筛查结果，支持按 NORMAL / PNEUMONIA 进行筛选。
3. 点击 **“详情”**，可查看该记录的完整信息（包含原图与 Grad-CAM 图）。
4. 若发现 AI 判定有误，可点击详情页底部的 **“反馈：AI判错了”** 按钮，选择真实结果进行纠错（该数据用于后续模型迭代）。

### 3.4 全息人体科普模块
1. 点击左侧导航栏的 **“全息人体”**。
2. 页面中央展示 3D 人体模型，您可以通过鼠标拖拽旋转、滚轮缩放。
3. 点击模型上的发光热点（气管 / 肺部 / 胸廓），右侧将弹出对应的医学解剖与肺炎病理科普卡片。
4. 左侧可切换“骨骼 / 呼吸 / 心血管”系统分层。

### 3.5 数据看板与模型信息
- **数据看板**：实时展示系统的筛查总量、阳性率、近期趋势及人群特征分析（如年龄段、性别分布）。
- **模型信息**：展示了系统所采用的 ResNet50 模型的各项硬核指标（Accuracy 97.43%、AUC 99.46%），以及 E1/E2/E3/E7 完整的实验消融对比结果，证明了模型选型的科学性。

## 4. 常见异常处理

| 异常现象 | 可能原因 | 解决办法 |
|---|---|---|
| 上传图片报错 | 格式不支持或超过 10MB | 请确保上传 JPG/PNG 格式且小于 10MB |
| 推理报错 `503` | 后端 ONNX 模型未加载 | 检查 `models/onnx/` 目录下是否有模型文件，重启后端 |
| 页面显示“Token 已过期” | 登录状态超时（默认 2 小时） | 重新登录即可 |
| PDF 导出空白 | 图片跨域或未加载完成 | 等待页面图片完全渲染后，再次点击导出 |
